# Dataset examples

`reference_session_v1/` is the tiny deterministic, relocatable session fixture
for [S2.1 session and shard layout](../../docs/development/specs/s2_session_shard_layout.md).
It contains two scenes, three episodes, two complete shards, canonical frame
records, and 4-channel IEEE-float32 WAV audio.

Regenerate it with `make regenerate-reference-dataset`.
