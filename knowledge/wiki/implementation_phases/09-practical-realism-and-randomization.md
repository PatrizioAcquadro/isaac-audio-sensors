# Implementation Plan 09 — Practical Realism and Randomization

Status: planned.

## Objective

Add realism only where it materially changes supported activity, localization, AV search or mobile tasks. Preserve [[decisions/robot-audition-fidelity|R10 scope/invariants]]; randomization cannot hide propagation defects.

## Subphase 09.1 — Task-Relevant Realism Model

#### Implementation

Prioritize received level, interference, channel mismatch, timing, motion and detector behavior from measured failures in maintained producers.

#### Key Decisions

Require concrete task value; do not recreate geometry occlusion or reopen full wave physics.

#### Problems / Limitations

Temporal perception research remains separate. Bench mismatches do not isolate a physical cause.

## Subphase 09.2 — Evidence-Backed Distributions and Transfer

#### Implementation

Select coherent bounded variations/presets from qualified geometry or existing physical evidence for a concrete consumer. Preserve correlations, audibility/level meanings and independent source/device effects.

#### Key Decisions

This phase owns distribution design/validation; no generic catalog is required by 08.3. Analytic remains maintained.

#### Problems / Limitations

Geometry is a reference only in its qualified domain. Physical transfer needs physical comparison; no automatic gain correction, self-noise estimate or mass-parallel claim follows.

## Subphase 09.3 — Validation and Cleanup

#### Implementation

Measure each effect in a supported consumer; keep useful controls in the existing GUI and remove redundant/ineffective surfaces. Reuse current RMS/freshness/exported audio tools.

#### Key Decisions

Noise, AGC and clipping controls need meaningful presets, not every possible knob.

#### Problems / Limitations

Simulated task utility and physical transfer are separate claims; calibrations remain explicit.

## Artifacts

Input: [[experiments/physical-signal-comparison|25-take physical comparison]]. Output: qualified ranges, task-effect evidence and documented exclusions; none implemented by this plan.

## Files

Implementation paths are selected only when a concrete effect/consumer is approved.
