# Security Policy

Report security concerns through a private GitHub security advisory once the
public repository is available. Until then, contact the repository maintainer
directly.

Do not include secrets, private recordings, restricted robot data, generated
media dumps, or local credential files in issues, pull requests, examples, or
test fixtures.

The package is simulation tooling. It should not be used as a safety-critical
perception component without independent validation, calibration, and runtime
safety controls.
