# Isaac Audio Sensors

`isaac_audio_sensors.omni` provides the Isaac Sim/Kit interface for robot-mounted audio arrays.

Open `Window -> Isaac Audio Sensors` to configure, validate, run, inspect, record, and export sensor output. The archive includes the maintained `isaac_audio_sensors` package and requires no separate package installation.

Source and documentation: <https://github.com/PatrizioAcquadro/isaac-audio-sensors>
