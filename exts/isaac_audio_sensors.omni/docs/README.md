# Isaac Audio Sensors

`isaac_audio_sensors.omni` provides the Isaac Sim/Kit interface for robot-mounted audio arrays.

Open `Window -> Isaac Audio Sensors` to configure, validate, run, inspect, record, and export sensor output. The archive includes the maintained package plus Auditok, room-acoustics, and FLAC dependencies, and requires no separate installation or runtime download. Auditok is qualified for explicit fixed-threshold use but is not selected by the extension until the Plan 03.3 consumer integration.

Source and documentation: <https://github.com/PatrizioAcquadro/isaac-audio-sensors>
