# Isaac Audio Sensors

`isaac_audio_sensors.omni` provides the Isaac Sim/Kit interface for robot-mounted audio arrays.

Open `Window -> Isaac Audio Sensors` to configure, validate, run, inspect, record, and export sensor output. The archive includes the maintained package plus room-acoustics and FLAC dependencies, and requires no separate installation or runtime download.

Source and documentation: <https://github.com/PatrizioAcquadro/isaac-audio-sensors>
