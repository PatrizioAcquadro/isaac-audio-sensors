# Extension Changelog

## 1.10.0 - Unreleased

- The extension uses the current dynamic-acoustics package behavior while preserving the existing extension binding and frame contracts.
- The standalone metadata is reduced to extension-specific behavior; complete technical documentation lives in the repository wiki.

## 1.9.0 - Unreleased

- Added the guided setup, validation, run, inspection, generic session recording, validation, split, and export workflow.
- Added recording progress, output inventory, and recovery behavior around simulator resets and partial writes.

## 1.8.0 - Unreleased

- Added the deterministic self-contained Kit archive with the maintained package vendored under `_vendor` and verified source provenance.

## 1.7.0

- Added `room_acoustics_srp`, tetrahedral array selection, elevation fields, and Doppler-aware package behavior to the extension controls and readouts.

## 1.6.0

- Added fixed and stage-anchored room controls, out-of-bounds policy, room diagnostics, and room visualization.

## 1.5.0

- Added bearing/RMS/timeline instruments, waveform and spectrogram preview, audition, viewport-follow and live-pose workflows, persistent USD debug geometry, and the runtime OmniGraph node.

## 1.0.0

- Added the reference Kit window for selected-prim binding, array/source metadata authoring, semantic discovery, sensor lifecycle, overlays, config import/export, JSON/JSONL export, and optional Replicator recording.
